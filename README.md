# Translate GUI

Перекладач написів в інтерфейсі Windows. Наведіть курсор на напис або виділіть текст і натисніть
**Ctrl + 0** — поруч з'явиться вікно з розпізнаним текстом і перекладом.

## Можливості

- **Два режими:** виділений текст, а якщо нічого не виділено — напис під курсором. Перемикач у вікні.
- **Розпізнавання тексту:** спершу UI Automation, у разі невдачі — OCR Windows (кирилиця й латиниця, режим «Авто»).
- **Переклад:** безкоштовний Google Translate, мову перекладу можна вибрати у вікні.
- **RDP і масштабування:** коректно працює через віддалений робочий стіл, з кількома моніторами й будь-яким масштабом.
- **Налаштування:** гаряча клавіша, світла й темна тема, програми-винятки, в яких гаряча клавіша не спрацьовує.

## Вимоги

- Windows 10 або 11
- Python 3.12
- Для OCR — встановлені мовні пакети Windows з розпізнаванням тексту (Параметри → Час і мова → Мова)

## Встановлення та запуск

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

Програма працює з області сповіщень (трею). Там же — налаштування гарячої клавіші, мова OCR і винятки.

## Збирання exe

```powershell
.venv\Scripts\pip install pyinstaller
.venv\Scripts\python build.py
```

Результат — один файл `dist\TranslateGUI.exe`, якому не потрібен встановлений Python.

## Де що зберігається

- Налаштування: реєстр, `HKCU\Software\TranslateGUI\TranslateGUI`
- Журнал: `%LOCALAPPDATA%\TranslateGUI\translategui.log`
